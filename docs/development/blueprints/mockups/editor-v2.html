What changed in this mockup
  • No borders: panels float over the canvas and separate by shade and shadow.
  • Nodes have a coloured header per family; pins and wires are coloured by data type.
  • Node selector: a searchable library dock on the left, plus a quick-add menu that opens where you press Space, right-click or double-click.
  • Drag a wire onto empty space: the menu only lists nodes that accept that type, and connects it for you.
  • Build / Test cases / Run history replace the tabs; settings live in a floating inspector.
  • Press Run to see wires and nodes animate.
  • The ⓘ on a node (hover it), in the library and in the quick-add menu opens a details window: overview with an example, every pin explained and what it is connected to, and the node's last run. Press i on a selected node, or Shift+Enter in the menu.
