# Draft release notes — Magnite local desktop preview

**Unreleased.** Version/tag, date, supported platform matrix, and final candidate
verification must be confirmed before publication. Current source metadata says 0.1.0;
this draft does not create a release or change that metadata.

Magnite brings model downloads, local adapter training, inference, and document
retrieval into a native desktop workspace. Train LoRA/QLoRA adapters, activate
them with the torch engine, and use local documents as chat context.

The proposed first distribution is source-first. Follow the
[installation guide](../INSTALL.md). No installers, cross-platform guarantees,
cloud training, or hosted inference are included in this release scope.

Read [known limitations](../LIMITATIONS.md), [storage/backup guidance](../STORAGE_AND_PRIVACY.md),
and the [verification report](VERIFICATION.md) before evaluating the preview.
The software uses the [MIT license](../../LICENSE); model and third-party licenses
remain separate.

Before publishing: finish the [release checklist](../../RELEASE_CHECKLIST.md), set
a private security contact, resolve asset provenance, and replace this draft's
status with the exact tested release tag and installation/support information.
