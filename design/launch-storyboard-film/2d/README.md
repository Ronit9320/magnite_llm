# 2D launch film

The 60 s launch film from the storyboard ("Magnite Launch Storyboard"), built in Blender as flat 2D animation.
One Blender scene per shot (S01–S14), all generated by the scripts in `scripts/`.

- `scripts/kit.py` — shared toolkit (flat materials, the logo disc, screen-locked titles, wordmark).
- `scripts/batch1.py` … `batch5.py` — the shots, in the storyboard's batches.
- `TEXT_TRACK.md` — the on-screen text and why it is there.

```bash
./run.sh build batch1          # rebuild a batch's scenes into film2d.blend (repeat for batch2..5)
./run.sh render S01 S02        # 1080p frames into renders/<shot>/
./run.sh preview name S01 ...  # mp4 + contact sheet
./final4k.sh                   # every shot at 3840x2160 and the 60 s master
```

Source art is read from `design/launch-storyboard-film/` in the main checkout (`assets/` SVGs, `footage/`
placeholders, `data/loss.csv`); override with `MAGNITE_FILM_SRC`. Renders, `film2d.blend` and `build/` are
not tracked. Needs Blender 5.x, ffmpeg and rsvg-convert.
