# Northstar Observatory visitor notes

This is a fictional observatory used only for a Magnite demonstration.

## Library

The observatory library opens Tuesday and Thursday from 18:00 to 21:00.
Visitors can read the observing notebooks and borrow printed sky maps during
these hours. The library is closed on other days in this fictional schedule.

## Equipment

The equipment cabinet is in Room Cedar. Return borrowed binoculars to the
cabinet after the session. The front desk handles maintenance requests; include
the equipment label and a short description of the problem.

## Preparing for a visit

Visitors should bring a notebook and a reusable water bottle. Leave the observing
room clear of bags so that everyone can move around the telescope safely.
